# Saúde Fácil (front-end)

Repositório do front-end do **Saúde Fácil**, aplicativo do Projeto Integrador "Saúde na Palma da Mão" do curso de Análise e Desenvolvimento de Sistemas da Faculdade Senac Pernambuco (turma 2025.32.185, semestre 2026.2).

O código fica na pasta [`front/`](front/). Comece pelo [`front/README.md`](front/README.md).

| Repositório | Conteúdo |
|---|---|
| saude-na-palma-da-mao (este) | Front-end PWA em React, TypeScript e Tailwind |
| [saude-palma-mao-api](https://github.com/jean-jpss/saude-palma-mao-api) | API REST em Node.js e Express |
| Repositório do banco | Scripts SQL do PostgreSQL |
